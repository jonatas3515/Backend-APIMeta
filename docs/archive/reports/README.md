# Relatórios Históricos

Este diretório preserva relatórios de versões anteriores para rastreabilidade e consulta histórica.

- Os documentos aqui arquivados não substituem a documentação operacional atual.
- Alguns diagnósticos, contagens, URLs, pendências e estados descritos podem estar desatualizados.
- Antes de tomar decisões de produção, valide o código, as migrations, a documentação atual e o estado efetivo do ambiente.
- Estes documentos não devem receber credenciais, tokens, chaves, payloads, logs brutos ou dados pessoais.
- O schema canônico permanece em `supabase/migrations/`.
- Scripts SQL históricos ficam em `docs/archive/sql-legacy/` e não devem ser executados sem revisão técnica e aprovação explícita.

|---|---|---|
| `SISTEMA_COMPLETO_RELATORIO.md` | Histórico | Registro consolidado de estado/arquitetura de versão anterior |
